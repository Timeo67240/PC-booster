# PC Booster

Outil gratuit pour Windows permettant de surveiller et d'optimiser son PC.

## Fonctionnalités

- Surveillance en temps réel du processeur, de la carte graphique et de la mémoire (températures, charge, fréquences)
- Lecture des capteurs matériels via LibreHardwareMonitor
- Outils d'optimisation en un clic [à vérifier]
- Interface en français [à vérifier]
- Gratuit, sans publicité, sans compte

## Configuration requise

- Windows 10 ou 11 (64 bits)
- Droits administrateur recommandés pour accéder à tous les capteurs

## Installation

1. Télécharger `PCBooster_Setup_1.0.0.exe` depuis la page Releases.
2. Lancer l'installateur et suivre les étapes.
3. Ouvrir PC Booster depuis le menu Démarrer.

Windows SmartScreen peut afficher un avertissement, l'application n'étant pas signée numériquement. Cliquer sur « Informations complémentaires », puis « Exécuter quand même ».
